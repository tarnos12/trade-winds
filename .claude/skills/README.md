# Vendored skills

These skill folders are copied verbatim from
[mattpocock/skills](https://github.com/mattpocock/skills) **v1.2.3** (MIT, see
`LICENSE-mattpocock-skills`) so that cloud/remote Claude Code sessions, which
don't have machine-local plugins, can use them.

To update: re-copy the folders listed in the plugin's `.claude-plugin/plugin.json`
from a newer release over these and bump the version above. Don't edit them in
place. Per-repo configuration for them lives in `docs/agents/`.
